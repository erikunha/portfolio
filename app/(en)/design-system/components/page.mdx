## Panel

| Prop | Type | Default | Required |
|---|---|---|---|
| `title` | `string` | · | yes |
| `marker` | `string` | · | yes |
| `as` | `'div' \| 'section' \| 'aside'` | `'div'` | no |
| `titleId` | `string` | · | no |
| `reveal` | `boolean` | `false` | no |
| `action` | `ReactNode` | · | no |

<Preview id="panel">
  <Panel className="w-full" marker="[+]" title="whoami"><p className="m-0 p-4">Body content.</p></Panel>
  <Panel className="w-full" as="aside" marker="[~]" title="status" titleId="panel-demo-title" action={<a href="#panel">link</a>}><p className="m-0 p-4">Landmark panel with an action.</p></Panel>
</Preview>

A bordered frame on an opaque `secondary-950` surface. The header holds a decorative `marker` (`aria-hidden`), the `title` as an `h3` and an optional `action` node after it. `as` picks the root element; `titleId` becomes the heading `id` and the root's `aria-labelledby`, which names a `section` or `aside` landmark by its title. Other `div` attributes pass through to the root.

**Reveal coupling:** `reveal` only sets `data-type-reveal` on the heading and `suppressHydrationWarning`, because the heading text is rewritten after hydration. The scroll typing itself comes from the app-wide `TypeReveal` island mounted by `GlobalMotion` in the root layout, which observes every `[data-type-reveal]` element. Without that island the attribute has no effect.

**Accessibility:** the title is the heading, so give each landmark panel its own `titleId`.

**Styling:** the frame rules live in `app/css/components-panel.css`. A section that needs a different title size or header layout scopes the change under its own class in its own stylesheet and selects `.panel-head` and `.panel-title`.

<h2 id="shell-and-module-patterns">Shell and module patterns</h2>

These pieces live in `components/`, not in `design-system/components`. They are documented here because pages outside the home page reuse them.

### MenuTrigger

The one control that opens the site menu. It is an icon-only 44px square button (the icon box is `--spacing-target` divided by `--phi` twice) named `Open menu`, with `aria-expanded`, `aria-controls` and `aria-haspopup="dialog"`. It is the first control at the left end of the header at every width, with the brand icon alone at the right end, so the menu is in the same place on the home page, `/links` and the design system.

<Preview id="menu-trigger">
  <MenuTrigger />
</Preview>

**Accessibility:** The name comes from `aria-label`, because the icon carries no text. Focus returns to the trigger when the menu closes.

<h3 id="position-line">Position line</h3>

Scroll progress is one decorative element, hidden from assistive technology with `aria-hidden="true"` (the browser scrollbar already conveys the position), restyled by width and fed by `--posf` (0 to 1).

| Viewport | Shape | Placement |
|---|---|---|
| From 1024px | 2px horizontal line | Across the top |
| Below 1024px | 2px vertical line | Right edge |

The line does not print and carries no number: no readout of the position appears in any control name.

### EqSpectrumStrip

A live spectrum under an EQ curve: log-frequency bars, one curve and an axis. Layers stack in one grid cell and the axis labels sit on grid tracks sized from the frequency positions, so nothing is absolutely positioned. The text alternative states the curve in words.

<Preview id="eq-spectrum-strip">
  <div style={{ width: '100%' }}>
    <EqSpectrumStrip spectrum={guitarPresentation[SITE_LOCALE.en].eqSpectrum} />
  </div>
</Preview>

**Motion:** Bars move on the beat. With the motion switch off, they hold a static level so the shape still reads. Bar height is the only data encoding; position on the axis carries frequency.

### Cover frame

The `links-thumb` class frames a video cover. The frame is always 16:9 and the `object-cover` image fills it. YouTube serves 4:3 covers with the picture centred between black bars, so a 16:9 frame trims only the bars and nothing of the picture; a cover that is not letterboxed, like the square preview below, is cropped to the frame instead. Colour comes from tokens in `theme.css`: the image is grayscale, then a signal-green layer multiplies over it (`--links-thumb-tint`). On hover or keyboard focus of the parent link, the layer relaxes to `--links-thumb-tint-reveal` and the image regains its colour.

<Preview id="cover-frame">
  <span className="links-thumb" style={{ width: '16rem' }}>
    <OptimizedImage src="/images/guitar-live.jpg" alt="" fill sizes="256px" className="object-cover" />
  </span>
</Preview>

**Motion:** The reveal fades over `--links-thumb-reveal-duration`. With the motion switch off, it switches without a transition.

**Accessibility:** The cover is decorative (`alt=""`); the link around it carries the video title. No text sits on a cover.

### CompanyLink

An external link to a company named in the text. It always opens in a new tab with `rel="noopener noreferrer"` and announces the new tab to screen readers in the page language (`(opens in a new tab)` or `(abre em uma nova guia)`, chosen by the required `locale` prop). When a page already announces the behaviour once, pass `describedBy` to point at that note instead.

<Preview id="company-link">
  <CompanyLink href="https://www.erikunha.dev" locale={SITE_LOCALE.en}>erikunha.dev</CompanyLink>
</Preview>

**Accessibility:** The hit area grows to `--spacing-target-compact` without changing the line height.
