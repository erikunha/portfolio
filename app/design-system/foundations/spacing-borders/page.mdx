<h2 id="target">Touch target</h2>

`--spacing-target` is 44px, the minimum width and height of every control. `--spacing-target-compact` is 28px for dense, non-primary controls.

<h2 id="layout">Layout tokens</h2>

Responsive tokens live in the `:root` block of `app/css/theme.css`; every page container reads them.

| Token | Below 768px | From 768px |
|---|---|---|
| `--space-gutter` | `clamp(16px, 4vw, 24px)` | `clamp(16px, 4vw, 24px)` |
| `--space-page-top` | 24px | 48px |
| `--space-section` | 32px | 48px |
| `--measure-page` | 1200px (home, summary, links) | 1200px |
| `--measure-read` | 72ch (cv, 404, design-system body) | 72ch |

Line heights: `--leading-tight` 1.1, `--leading-snug` 1.35, `--leading-body` 1.6.

<h2 id="borders">Borders</h2>

| Token | Value | Use |
|---|---|---|
| `--border-width` | 1px | Borders and dividers |
| `--radius-none` | 0 | Sharp controls |
| `--radius-control` | 2px | Maximum control radius |

No component uses a radius above 2px. The traffic-light dots in `WindowChrome` are the one round shape.

<h2 id="focus">Focus</h2>

Keyboard focus uses `:focus-visible` with a 2px signal outline and a 2px offset. Never remove the outline without a replacement of equal contrast.
