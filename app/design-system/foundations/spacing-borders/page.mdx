<h2 id="phi">Golden-ratio spacing</h2>

Page rhythm steps through one set of tokens, each the previous times `--phi` (1.618). Gaps, padding, heading margins and the two-column splits on the guitar module, `/links` and the design system all read them.

| Token | Value | Size |
|---|---|---|
| `--phi-space-1` | 0.5rem | 8px |
| `--phi-space-2` | `--phi-space-1` × `--phi` | 13px |
| `--phi-space-3` | `--phi-space-2` × `--phi` | 21px |
| `--phi-space-4` | `--phi-space-3` × `--phi` | 34px |
| `--phi-text-1` | `--text-xs` × `--phi-root` (1.272) | about 15px |
| `--phi-inv` | 1 ÷ `--phi` | 0.618 |
| `--phi-pair-columns` | `minmax(0, 1.618fr) minmax(0, 1fr)` | 1.618 : 1 |

Whole-page type does not use phi: a 1.618 step from a 12px base jumps to 19px and then 31px, too coarse for dense monospace text. Only `--phi-text-1` takes the half step, for stat values. Pairs split 1.618 : 1 from 1024px and stack below it; on a phone every level is one centered column.

<h2 id="target">Touch target</h2>

`--spacing-target` is 44px, the minimum width and height of every control. `--spacing-target-compact` is 28px for dense, non-primary controls.

<h2 id="layout">Layout tokens</h2>

Responsive tokens live in the `:root` block of `app/css/theme.css`; every page container reads them.

| Token | Below 768px | From 768px |
|---|---|---|
| `--space-gutter` | `clamp(16px, 4vw, 24px)` | `clamp(16px, 4vw, 24px)` |
| `--space-page-top` | 24px | 48px |
| `--space-section` | 32px | 48px |
| `--measure-page` | 1200px (home, summary, links) | 1200px |
| `--measure-read` | 72ch (cv, 404, design-system body) | 72ch |

Line heights: `--leading-page-tight` 1.1, `--leading-page-snug` 1.35, `--leading-body` 1.6. The page-scoped names keep Tailwind's built-in `leading-tight` and `leading-snug` scale intact.

<h2 id="borders">Borders</h2>

| Token | Value | Use |
|---|---|---|
| `--border-width` | 1px | Borders and dividers |
| `--radius-none` | 0 | Sharp controls |
| `--radius-control` | 2px | Maximum control radius |

No component uses a radius above 2px. The traffic-light dots in `WindowChrome` are the one round shape.

<h2 id="focus">Focus</h2>

Keyboard focus uses `:focus-visible` with a 2px signal outline and a 2px offset. Never remove the outline without a replacement of equal contrast.
