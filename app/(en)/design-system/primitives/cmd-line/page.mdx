<h2 id="props">Props</h2>

| Prop | Type | Default | Required |
|---|---|---|---|
| `command` | `string` | none | yes |
| `user` | `string` | none | yes |
| `prompt` | `string` | `':~$'` | no |
| `output` | `ReactNode` | none | no |
| `className` | `string` | none | no, merged after the base classes |
