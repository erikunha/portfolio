<h2 id="type-scale">Type Scale</h2>

The base `h1` rule uses `--font-display`, Inter at weight 900. Body text, controls
and other base headings use `--font-mono`, JetBrains Mono. Consumers can override these rules. Both stacks reference
the existing `next/font/local` variables.

| Token | Utility | Size |
|---|---|---|
| `--text-xs` | `text-xs` | 12px below 768px; at least 13px from 768px |
| `--text-sm` | `text-sm` | 14px |
| `--text-base` | `text-base` | 16px |
| `--text-lg` | `text-lg` | 18px |
| `--text-xl` | `text-xl` | 20px |
| `--text-2xl` | `text-2xl` | 24px |
| `--text-3xl` | `text-3xl` | 32px |
| `--text-5xl` | `text-5xl` | 48px |
| `--text-7xl` | `text-7xl` | 64px |

`--text-min` rises from 12px to 13px at 768px. `--text-xs` uses that floor.
Use these tokens for small text; fixed pixel utilities do not inherit the floor.
Sizes use rem units so they follow the reader's default font size.

The base `h1` is 32px, rising to 48px at 1280px. `h2` is 20px, rising to
24px at 768px. `h3` is 16px. Consumers can select larger steps for display text.

Small and medium Buttons have a 44px minimum height. Small Buttons use 10px
horizontal padding; medium and large Buttons use 14px. Large Buttons have a
52px minimum height. CopyButton has a 44px minimum width and height in every state.

<h2 id="motion">Motion</h2>

Components use Tailwind duration and easing utilities, plus named CSS animations.
Reduced-motion handling is defined in `app/css/animations.css`, `crt.css`,
`components-*.css` and component logic. Check the affected animation rather than
assuming one global rule disables all motion.

Module headers reveal text in character steps as they enter the viewport. Their caret
blinks four times and then stays solid. The MOTION toggle and OS reduced motion
disable this effect. Browsers without scroll-driven animation support show static headers.

| Utility | Value | Usage |
|---|---|---|
| `duration-[80ms]` | 80ms | micro transitions (hover, press) |
| `duration-100` | 100ms | fast UI feedback |
| `duration-200` | 200ms | standard transitions |
| `ease-out` | Shared | easing used by Button and Field |

<h2 id="layers">Layers</h2>

z-index is applied with Tailwind `z-[N]` utilities, there is no CSS-var token
layer. The cross-cutting contract:

| Layer | z-index | Usage |
|---|---|---|
| content | `z-[1]` | page content above the CRT overlay |
| header chrome | `z-[110]` | DesktopTopbar / StatusBar (MobileTitleBar `z-[109]`) |
| mobile dock | `z-[120]` | bottom navigation dock |
| skip link | `9999` | skip-to-content link, always on top |

Component-local stacking (CRT effect layers 1 to 5) is intentionally not part of the
contract.
